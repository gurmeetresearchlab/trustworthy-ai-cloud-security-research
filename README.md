
# Trustworthy AI for Cloud Application Security

### Explainable, Generalisable and Resource-Aware Vulnerability Triage

**Research Project | Gurmeet Research Lab**

---

## Overview

This research explores trustworthy AI approaches for vulnerability triage in cloud-connected applications and APIs. It focuses on improving the reliability of AI-assisted security analysis through explainability, generalisation, robustness, and computational efficiency.

Modern cloud applications combine source code, APIs, identity controls, databases, third-party services, and automated deployment pipelines. Identifying and prioritising security vulnerabilities within these environments remains a challenging task.

This project investigates how AI can assist security teams in prioritising vulnerability findings while maintaining transparency, reliability, and practical usability.

## Research Objectives

- Evaluate AI-assisted vulnerability triage for cloud-connected software.
- Investigate explainable AI approaches for security-related predictions.
- Examine model generalisation across different software projects.
- Analyse false positives and the reliability of vulnerability classification.
- Evaluate computational efficiency and resource requirements.
- Explore a human-in-the-loop approach to security decision-making.

## Research Questions

1. How effectively can AI models prioritise vulnerability findings in cloud-connected applications?
2. Can explainable AI improve the transparency and interpretability of vulnerability triage?
3. How well do AI models generalise across different projects and datasets?
4. How can false-positive burden, robustness, and prediction reliability be evaluated?
5. What trade-offs exist between model performance, explainability, and computational cost?

## Proposed Methodology

The proposed research will investigate and compare:

- Static-analysis security baselines
- Conventional machine-learning models
- Selected explainable AI techniques
- Public and appropriately licensed vulnerability datasets
- Cross-project and time-separated evaluation
- Human-in-the-loop vulnerability triage

## Evaluation Metrics

The research may evaluate:

- Precision
- Recall
- F1-score
- False-positive burden
- Generalisation performance
- Model calibration
- Robustness
- Explanation faithfulness
- Computational cost

## Research Scope

The primary focus is application security, vulnerability analysis, cloud-connected software, API security, trustworthy AI, and responsible security automation.

The research aims to support security practitioners by investigating AI methods that are more transparent, reliable, and practical for real-world vulnerability assessment.

## Ethical Considerations

This research will prioritise responsible cybersecurity research practices, lawful use of datasets, reproducibility, transparency, and responsible disclosure where applicable.

Experiments will be conducted using authorised environments and appropriately sourced research data.
